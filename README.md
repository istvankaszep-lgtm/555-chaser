# 555-chaser
this is a led chaser with red leds.

How to use it: to power it you need max a 5V output and also you need 2 female to male jumper wire
for power source you can use an arduino or get an usb cable and cut one end of it and connect them using the jumper wires
and then plug te usb cable in a 5V charger or in a laptop/pc.

I made this proiect to test out hack club/blueprint and to learn how to use kicad, also this is my very first proiect.
